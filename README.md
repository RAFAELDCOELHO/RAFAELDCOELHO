# Rafael D. Coelho

Independent researcher. Public work lives in these repositories.

## Flagship

- **[PersonaCore](https://github.com/RAFAELDCOELHO/PersonaCore)** — from-scratch on-device GPT with weight-based personalization, plus an adversarial privacy audit of LoRA memory. Clone and `make demo`. Slim checkpoint: [m1-demo-v1](https://github.com/RAFAELDCOELHO/PersonaCore/releases/tag/m1-demo-v1).
- **[autonomous-hedge-fund](https://github.com/RAFAELDCOELHO/autonomous-hedge-fund)** — BrazilBench lives here. Offline baselines (Buy and Hold, MACD, SMA) on frozen B3 splits: `make bench`. No API key.
- **[brazilfi](https://github.com/RAFAELDCOELHO/brazilfi)** — Python SDK for Bacen, IBGE, and Tesouro Direto. MIT.

## Same stack

- **[personacore-np](https://github.com/RAFAELDCOELHO/personacore-np)** — inference engine for the 13.9M GPT in pure NumPy, optional MLX. No PyTorch at serve time.
- **[tensorforge](https://github.com/RAFAELDCOELHO/tensorforge)** — from-scratch deep learning framework. Retrained a real GPT checkpoint; forward and backward match PyTorch.
